# 🍽️ Restaurant Landing System

A high-performance, accessible, and easily configurable landing page system for restaurants, built with React 19, TypeScript, Vite, and Tailwind CSS v4.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run linter
npm run lint

# Build for production
npm run build
```
